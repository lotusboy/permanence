# runtime/ — tools a session calls

Each tool's own header comment is its full reference. `docs/TOOLS.md` lists every script and what it
writes.

The project team's tools (`spend.sh`, `save-report.sh`, `ratify.sh`, `health-signal.py` and the rest)
were described here until v1.12.0. They moved to the bakehouse plugin, with their docs:
<https://github.com/lotusboy/bakehouse>.
